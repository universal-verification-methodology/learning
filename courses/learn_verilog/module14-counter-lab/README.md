# Module 14: Counter patterns

**Kind:** lab · Primary lab: counter-lab · **Shipped**

[← One-driver nets](../module13-one-driver/README.md) · [Course README](../README.md) · [Shift-register patterns →](../module15-shift-register-lab/README.md)

## Outcomes

After this module you can explain and practice the ideas taught by **counter-lab**, in the browser and/or with real Verilog.

## Two tracks (pick one or both)

### Track A — Real Verilog (hands-on)

1. Open [EXAMPLES.md](EXAMPLES.md) and write / edit the suggested sketch.
2. Complete [CHECKLIST.md](CHECKLIST.md) in a local .v file (iverilog optional).
3. Optional self-check: ./scripts/module.sh 14 --check (from course root).

### Track B — Browser lab (online)

1. Local: [http://127.0.0.1:8080/tools/counter-lab/index.html](http://127.0.0.1:8080/tools/counter-lab/index.html)
2. Live: [https://universal-verification-methodology.github.io/learning/tools/counter-lab/](https://universal-verification-methodology.github.io/learning/tools/counter-lab/)
3. Load the **starter example**, then work challenges.
4. Check off the Track B items in [CHECKLIST.md](CHECKLIST.md).

> Browser labs teach literacy — they do not replace writing synthesizable RTL you will commit.
